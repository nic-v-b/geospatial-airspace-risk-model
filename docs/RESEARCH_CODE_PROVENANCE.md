# Research-code provenance

The code in this repository is a cleaned reference implementation of the methodology described in the 2025 Journal of Open Aviation Science paper.

It is **not** a bit-for-bit archival snapshot of the original development environment.

After the paper was developed, the underlying research code continued to evolve as part of a broader PhD project on reusable 4D airspace modeling. That later project added computational benchmarking, richer diagnostics, expanded weather processing, revised risk outputs, clustering experiments, and thesis-specific visualization workflows.

To keep this repository useful and interpretable:

- only methodological concepts needed for the paper are implemented here;
- later thesis experiment orchestration is intentionally excluded;
- the synthetic example avoids external credentials and large datasets;
- scientific concepts remain traceable to the publication;
- later thesis-specific results should not be interpreted as paper results.

The larger thesis repository remains private until the PhD defense.
